# Data Analytics Project

## Overview

This project focuses on end-to-end data analytics using Python, SQL, and Power BI. The workflow includes loading and cleaning the dataset, performing Exploratory Data Analysis (EDA), executing SQL queries for business insights, building an interactive Power BI dashboard, and creating reports and presentations for stakeholders.

The main objective of this project is to transform raw data into meaningful insights and visualizations that support data-driven decision-making.

---

## Dataset

* Dataset Type: Structured CSV/Excel dataset
* Source: Public/Company/Internal dataset
* Size: Multiple rows and columns containing transactional/business information
* Features Included:

  * Customer details
  * Sales information
  * Product/category data
  * Dates and transactions
  * Performance metrics

## Project Workflow

### 1. Data Loading

* Imported dataset using Python
* Checked dataset structure and data types
* Verified missing values and duplicates

### 2. Exploratory Data Analysis (EDA)

* Analyzed trends and patterns
* Generated summary statistics
* Identified correlations and outliers
* Created visualizations for better understanding

### 3. Data Cleaning

* Removed duplicate records
* Handled missing/null values
* Standardized column names and formats
* Corrected inconsistent data entries

### 4. SQL Analysis

Performed SQL queries using PostgreSQL/MySQL/SQL Server to:

* Filter and aggregate data
* Use joins and subqueries
* Create KPIs and business metrics
* Analyze customer and sales performance
* Generate analytical reports

### 5. Power BI Dashboard

Built an interactive dashboard containing:

* KPI cards
* Sales trends
* Customer insights
* Category performance
* Filters and slicers for dynamic analysis

### 6. Reporting & Presentation

* Created a detailed analytical report
* Designed a professional presentation using Gamma AI
* Summarized insights and recommendations

## How to Run the Project

### Python Setup

1. Install required libraries:

```bash
pip install pandas numpy matplotlib seaborn
```

2. Run the Jupyter Notebook or Python script:

```bash
jupyter notebook
```

### SQL Setup

* Import dataset into PostgreSQL/MySQL/SQL Server
* Execute SQL scripts from the `sql_queries` folder

### Power BI

* Open the `.pbix` file in Power BI Desktop
* Refresh dataset connection if required
